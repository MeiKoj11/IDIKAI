How to use this page

This is a general space for you, with a class notebook and a storage locker.

The class notebook is an online notebook for general lessons and notes. Anything important you write can be added to any section — new grammar rules or vocab, for example — and an option to save a note will pop up whenever you're in Grammar or Vocab.

The storage locker is for saving PDFs or any other ad hoc material. It can be opened any time.
